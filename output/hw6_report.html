What each layer catches on its own

Code strips hidden text, but can't remove a visible "correction". Design locks the numbers and the decision, but missed a visible "vendor of record" claim. Prompt handles the judgment calls, but it only works when the model follows it. All three together: nothing got through. These rows are separate runs from Problem 6 (the no-defenses row was fooled 3 times there, versus 4 in Problem 5, because the model varies from run to run); "all" is the final patched agent.
